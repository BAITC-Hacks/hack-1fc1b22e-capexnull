# Аким на 5 часов — каркас

Стек: Node.js 22+ и браузерные ES-модули без зависимостей. Запуск: `npm start`, затем `http://127.0.0.1:3000`.

Поток: UI → Scenario/Input → Validator → Deterministic Mathematical Engine → структурированный CalculatedResult → Agentic AI → Result/Visualization UI.

- `src/ui`: пользовательский интерфейс и координация потока; состояния `initial`, `processing`, `result`, `validation-error`, `disabled`. Текущий экран отключает анализ до реализации модели.
- `src/scenario`: исходные условия MATAN-only и один подтверждаемый набор ровно из пяти решений. Порядок решений семантически незначим; район задаётся в решении для районных мер.
- `src/validator`: будущая проверка допустимости до расчёта: количество, уникальность, районы, бюджет и совместимость. Пока возвращает явный отказ.
- `src/engine`: единственный источник численных результатов; будущие данные, каталог, эффекты, лаги, синергии, ограничения и Score. Контракт `CalculatedResult` определён в JSDoc. Расчёт пока явно недоступен; тестовые численные результаты не подставляются.
- `src/ai`: получает только CalculatedResult, возвращает текстовые сильные стороны, риски, компромиссы и рекомендации. Не определяет Score, стоимости, показатели, эффекты или ограничения. Провайдер и ключи отсутствуют.
- `src/result`: отображение рассчитанных значений и объяснения, без математических преобразований. Место для будущей визуализации.

100 и 52.56 на стартовом экране — заданные исходные условия, не результат расчёта. Остаток равен исходному бюджету только для пустого набора; после реализации выбора его рассчитывает математический модуль.

Неожиданные события не реализуются. В дальнейшем отдельный адаптер сценария сможет подготовить входные условия до Validator; генерация событий и управление динамическим сценарием остаются вне математического ядра.

Первый функциональный блок: определить исходные данные и каталог в engine, затем реализовать допустимость набора в Validator. Каркас не содержит алгоритма Score, оптимизатора или deployment. Существующие файлы организатора сохраняются.
